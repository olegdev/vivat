# Контентные страницы b2b: Контакты и Доставка — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** свёрстать две контентные страницы дилерского раздела — Контакты и
Доставка, 1440 и 360 — вместе с общими частями, которые понадобятся остальным
девяти страницам секции.

**Architecture:** оболочка страницы остаётся разметкой самой страницы (шесть
строк `general-container`); весь общий объём выносится в три новых партиала —
`menu-b2b`, `for-business-header`, `accordion`. Карта Контактов не новый блок,
а четвёртый режим существующего `partials/stores.html`. Ничего из готового не
переписывается.

**Tech Stack:** Vite 6, Tailwind v4, ванильный JS, включения через
`<!--#include partials/NAME.html -->`, Яндекс Карты v3.

**Spec:** `docs/superpowers/specs/2026-08-17-b2b-content-pages-design.md`

## Global Constraints

- **Тестов в обычном смысле в проекте нет.** Цикл проверки задачи — три штатные
  проверки из `CLAUDE.md`: `node scripts/fig.mjs inst <id>` на каждом инстансе
  (не `tree`), `npm run audit <page> <selector> <instance-id>` на блоках с
  переопределённой копией, `npm run shot <page>` с **обязательным просмотром
  PNG**. Задача не закрыта, пока все три не пройдены.
- **Ничего не выдумывать** — ни подписи, ни иконки, ни размера, ни поведения.
  Нечитаемое значение измерить и спросить, слот оставить пустым, вопрос — в
  `BACKLOG.md`.
- Числа брать из `fig.mjs`, не из скриншота. Цвет текста на цветной заливке
  подтверждать живым рендером.
- Долги и открытые вопросы — только в `BACKLOG.md`, **никогда** в комментарий
  к разметке.
- Структура — HTML, поведение — JS. Повторяющийся блок живёт как `<template>`
  в своём партиале, скрипт его клонирует и никогда не собирает разметку из
  строк.
- Кастомный класс, используемый с вариантом (`max-md:foo`), обязан быть
  `@utility`, не `@layer components`.
- Мобильное выражается `max-md:` в месте применения; в `app.css` уходит только
  то, чего утилитами не выразить.
- Токены из `@theme` в `src/styles/app.css` — единственный источник правды.
  `bg-overlay-light`, не `bg-[#141414]/10`.
- Обе страницы — `data-user="dealer"`.
- Файл Figma: `locvXJpmVZqIMVwPoumae3`.
