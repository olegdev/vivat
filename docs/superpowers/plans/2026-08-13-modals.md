# Модальные окна B2b additional — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** четыре модальных окна — заявка на дилерство, вход в дилерский режим, подписка на новости, письмо директору — доступные с обеих половин сайта на 1440 и 360.

**Architecture:** одна оболочка в `app.css` (`.modal-scrim` / `.modal-panel`), партиал на окно, тонкий хаб `partials/modals.html` с четырьмя вложенными `#include`, один компонент `components/modals.js` с четырьмя швами. Существующие пустые ссылки в шапке, подвале и на дилерской главной получают `data-modal-open`.

**Tech Stack:** Vite + Tailwind v4, ванильный JS, партиалы через `scripts/vite-plugin-includes.mjs`. Тестов в проекте нет — проверка это `npm run build`, `node scripts/crop.mjs` против рендеров из Figma и разовый Playwright-прогон поведения.

**Spec:** `docs/superpowers/specs/2026-08-13-modals-design.md`

## Global Constraints

- **Ничего не выдумывать.** Подпись, иконка, размер, поведение — только из макета. Нечитаемое место: измерить, оставить пустым, вопрос в `BACKLOG.md`.
- **Структура — HTML, поведение — JS.** Компонент не собирает разметку строками.
- Один партиал == один будущий Blade-партиал.
- Долги — в `BACKLOG.md`, не в комментариях к разметке.
- Токены из `@theme` в `src/styles/app.css`; `bg-overlay-strong`, а не `bg-[#141414]/90`.
- Мобильное — через `max-md:` на месте использования.
- Кастомный класс под вариантом обязан быть `@utility`, не `@layer components`.
- Опечатки макета исправляем и записываем расхождение.
- Ширина панели 1440: **485**, скрим `#141414/0.9` = `bg-overlay-strong`.
- Рендеры для сверки лежат в `/tmp/claude-1000/-srv-vivat-dev/3c14c54b-ed1d-4c33-a627-3e2dd3e8b950/scratchpad/`: `mo-dealer.png` (485×701), `mo-login.png` (485×323), `mo-sub.png` (485×343), `mo-mail.png` (485×811), `mm-dealer.png`, `mm-mail.png` (360×800). Если их нет — перекачать через `mcp__plugin_figma_figma__get_screenshot` по node-id из спеки.

`src/components/modals.js`:

```js
// Модальные окна секции B2b additional — заявка на дилерство, вход в
// дилерский режим, подписка на новости, письмо директору.
//
// Структура — HTML: каждое окно это свой партиал, здесь только поведение.
//
// ШВЫ. Каждая форма уходит в свою функцию, и это единственное место, где в
// Blade появится запрос:
//
//     await fetch("/dealer/request", { method: "POST", body: new FormData(form) });
//
// Экрана «отправлено» в макете нет ни у одного окна, поэтому все четыре
// просто закрываются. Вход дополнительно уводит на дилерскую главную —
// это наше решение, а не макет (см. BACKLOG).
const SEAMS = {
  "dealer-request": (values) => void values,
  "dealer-login": (values) => {
    void values;
    window.location.href = "../dealer/main.html";
  },
  subscribe: (values) => void values,
  director: (values) => void values,
};

export function initModals() {
  const panels = new Map(
    [...document.querySelectorAll("[data-modal]")].map((el) => [el.dataset.modal, el])
  );
  if (!panels.size) return null;

  let openName = null;
  let opener = null;

  function close() {
    if (!openName) return;
    panels.get(openName).classList.remove("is-open");
    openName = null;
    document.body.classList.remove("overflow-hidden");
    opener?.focus();
    opener = null;
  }

  function open(name, trigger) {
    const panel = panels.get(name);
    if (!panel) return;
    const previous = opener;
    close();
    opener = trigger ?? previous ?? null;
    openName = name;
    panel.classList.add("is-open");
    document.body.classList.add("overflow-hidden");
    panel.querySelector("input, textarea, button")?.focus();
  }

  document.addEventListener("click", (e) => {
    const trigger = e.target.closest("[data-modal-open]");
    if (trigger) {
      e.preventDefault();
      return open(trigger.dataset.modalOpen, trigger);
    }
    if (e.target.closest("[data-modal-close]")) return close();
  });

  // Клик мимо панели — на перехвате, а не на всплытии: см. SOLUTIONS.md ›
  // «Клик „мимо панели“ ловится на перехвате, а не на всплытии».
  document.addEventListener(
    "pointerdown",
    (e) => {
      if (!openName) return;
      if (!e.target.closest("[data-modal-panel]")) close();
    },
    true
  );

  document.addEventListener("keydown", (e) => {
    if (e.key === "Escape") close();
  });

  panels.forEach((panel, name) => {
    panel.querySelector("[data-modal-form]")?.addEventListener("submit", (e) => {
      e.preventDefault();
      const form = e.currentTarget;
      if (!form.reportValidity()) return;
      const values = Object.fromEntries(new FormData(form));
      close();
      SEAMS[name]?.(values);
    });
  });

  return { open, close };
}
```
