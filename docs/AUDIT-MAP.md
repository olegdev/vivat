# Реестр блоков для аудитов

Что проверять и чем. Каждая строка — один блок: селектор в нашей разметке и
узел в Figma, отдельно на каждую ширину. `npm run audit:all` идёт по этому
файлу и прогоняет три аудита на каждой строке.

Реестр существует потому, что все аудиты **поблочные**: на вход им нужны
селектор и id инстанса, и покрытие целиком зависит от того, куда их направили.
Пока списка не было, «прогнать аудиты» означало «вспомнить, что проверить», и
половина забывалась — так плашка в характеристиках дожила до клиента с кеглем
14/18 вместо 16/24, хотя `audit:type` нашёл бы её за секунду.

## Как читать строку

```
| имя блока | селектор | 1440 | 768 | 360 | чем |
```

- **селектор** — наименьший элемент, оборачивающий блок. Раннер берёт первый
  ВИДИМЫЙ на этой ширине, поэтому один селектор годится для всех трёх.
- **1440 / 768 / 360** — id инстанса в СВОЁМ кадре каждой ширины. `—` значит
  кадра нет: планшет нарисован для пяти страниц, у части мобильных блоков
  своего узла тоже нет.
- **чем** — какие аудиты гонять: `t` кегли (плюс перенос строк и ширина
  уложенного текста — метрики шрифта), `b` ящики, `s` отступы секций,
  `i` иконки (вариант символа по `docs/ICON-MAP.md`), `c` копия (порядок и
  текст строк — только там, где инстанс несёт переопределения: заголовки
  секций, ряды кнопок, меню).
  Пусто = `t b`. `s` ставится один раз на страницу, на строке `СТРАНИЦА`.
  Пятый, `audit:fit` (горизонтальная прокрутка и перекрытое управление),
  строк не требует — раннер гонит его по каждой странице реестра сам.

`b` печатает подсказками ещё и горизонталь (смещение от левого края родителя,
ширину у пар одной высоты) и цвет (заливка, обводка с толщиной по сторонам,
прозрачность) — только у пар, чьи родители тоже спарены; см. SOLUTIONS ›
«`audit:box` сверяет и горизонталь, и цвет».

Флаги для отдельных строк пишутся в конце селектора после `#`:
`#flatten=2` для аудита отступов, `#depth=4` для аудита ящиков,
`#click=sel,sel` — состояния: раннер жмёт эти элементы до замера ящиков
(открытая панель прайс-листа, ящик фильтров, шаг меню). Селектор в `#click`
не может содержать пробелы и `|`; запятая разделяет шаги.
`#session=dealer` — страницы раздела «Для бизнеса» шарятся и читают, кто
смотрит, из localStorage; кадры рисуют дилерскую шапку, а свежий браузер
аудита — покупательскую. Флаг ставится на строки шапки таких страниц.
`#height=796` — высота окна для `audit:flow` на 1440: с 1440 шапка, алерт и
герой занимают весь экран (BACKLOG › «Порог полноэкранного героя»), и при
окне 900 герой 744 вместо нарисованных 640. Ставится на СТРАНИЦА главных.
